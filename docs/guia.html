Guia do alg

O alg se lê como o pseudocódigo do livro e compila para C. Você escreve o algoritmo; ele cuida da leitura rápida da entrada, do long long, do resto negativo e da estrutura de dados certa. Cada exemplo abaixo traz a mesma solução em C++ ao lado, para você ver o que deixa de escrever.

Rodar um programa

O arquivo tem extensão .alg. A primeira linha diz o idioma das palavras-chave: #lang pt ou #lang en.

./alg sol.alg                 # compila e roda; digite a entrada
./alg sol.alg < entrada.txt   # ou mande um arquivo
./alg -O -o sol sol.alg       # executável rápido, sem checagens (para submeter)
./alg -O --emit-c sol.alg     # mostra o C gerado (dá para enviar ao juiz como C)

Sem -O, índice fora do vetor, divisão por zero e estrutura vazia viram erro com a linha: erro (linha 12): índice 7 fora de 0..5. Com -O essas checagens saem e o código fica tão rápido quanto C.

Problemas de maratona, lado a lado

As soluções em alg foram compiladas e testadas com as entradas de exemplo. As versões em C++ são as que um competidor escreve no dia a dia (com sync_with_stdio(false)).

soma de prefixos · O(n + q)

Soma de intervalo

Dado um vetor de n números, responda q perguntas "quanto dá a soma de a[l..r]?" (posições a partir de 1). Entrada: 5 3 / 1 2 3 4 5 / 1 5 / 2 3 / 4 4 → 15 5 4.

  • #decl pre[n + 1] aparece antes de n ser lido: o vetor só é criado (zerado) no primeiro uso.
  • Todo inteiro já é de 64 bits, então a soma não estoura como estouraria com int.
programação dinâmica · O(n · W)

Mochila 0/1

n itens com peso e valor, mochila com capacidade W: qual o maior valor sem passar do peso? Entrada: 4 7 / 1 1 / 3 4 / 4 5 / 5 7 → 9.

  • O para ainda não conta de trás para frente; por enquanto, use cap = w - c como no exemplo.
  • Com -O, este laço roda em 0,56× o tempo do C++ no benchmark do projeto (o compilador gera C que o gcc vetoriza).
guloso + ordenação · O(n log n)

Máximo de atividades sem sobreposição

Cada atividade tem início e fim. Quantas dá para fazer sem que duas se sobreponham? Ordene pelo fim e pegue a próxima que começa depois da última escolhida. Entrada: 4 / 1 3 / 2 5 / 3 9 / 6 8 → 2.

  • Tuplas comparam campo a campo, como pair: (fim, inicio) ordena pelo fim e desempata pelo início.
  • ordenar usa radix sort para inteiros e introsort para tuplas e reais; nos testes ficou 0,46× o tempo do std::sort.
busca binária na resposta · O(n log S)

Menor capacidade de caminhão

Pacotes em ordem precisam ir em no máximo k viagens. Qual a menor capacidade de caminhão que dá conta? Teste capacidades com busca binária. Entrada: 5 3 / 4 2 7 3 5 → 8.

  • A função não declara o tipo dos parâmetros: o compilador descobre pelas chamadas e gera uma versão em C para cada combinação de tipos.
  • Vetores passam por referência, sem cópia; o const vector<long long> & do C++ vira só pesos.
hash · O(n) + ordenação das chaves

Frequência de cada valor

Leia n números e mostre cada valor distinto com quantas vezes aparece, em ordem crescente. Entrada: 6 / 5 1 5 3 1 5 → 1 2 / 3 1 / 5 3.

  • O mapa é um hash (rápido como unordered_map) e percorre as chaves em ordem, como map. Você não precisa escolher entre os dois.
  • A semente do hash muda a cada execução: entradas feitas para derrubar unordered_map não funcionam aqui.
grafo · BFS · O(n + m)

Menor número de estradas

Cidades 1..n e m estradas de mão dupla. Quantas estradas no mínimo da cidade 1 até a n? Entrada: 5 5 / 1 2 / 2 3 / 1 4 / 4 5 / 3 5 → 2.

  • grafo(n) é não dirigido: aresta(u, v) já liga os dois lados. Esquecer a volta é um bug clássico que aqui não existe.
  • O grafo vira uma lista de adjacência compacta na primeira consulta; nos testes, BFS ficou 0,45× o tempo da versão com vector<vector>.
menor caminho com pesos · O((n + m) log m)

Dijkstra

Grafo dirigido com pesos positivos: menor distância da cidade 1 até cada cidade. Entrada: 3 4 / 1 2 6 / 1 3 2 / 3 2 3 / 2 3 4 → 0 5 2.

  • heap() já tira o menor primeiro: nada de greater<> nem de inverter sinal. Para o maior primeiro, heap(maior).
  • INF vale 1018, com folga para INF + w não estourar. Num vetor : int32, o compilador guarda INF de um jeito especial e ele continua valendo INF quando lido.
  • escrever(dist) escreve o vetor inteiro separado por espaço.
referência rápida

Desempenho
